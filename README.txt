# Para mi niña ❤️

Página romántica mobile-first creada para el 7-10-2026.

## Archivos
- index.html
- style.css
- script.js

## Publicarla gratis con GitHub Pages

1. Crea o entra a tu cuenta de GitHub.
2. Crea un repositorio nuevo, por ejemplo: `para-mi-nina`.
3. Sube los tres archivos de esta carpeta.
4. En el repositorio ve a **Settings → Pages**.
5. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Guarda.
7. GitHub te mostrará la URL pública, normalmente:
   `https://TU-USUARIO.github.io/para-mi-nina/`

Luego puedes mandar ese link por WhatsApp.

## Nota
La página no depende de imágenes externas ni de código extraño. Las referencias visuales son CSS y tipografía web.
